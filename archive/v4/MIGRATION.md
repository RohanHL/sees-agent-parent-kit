Useful tentative calendar blocks remain possible when explicitly wanted, labeled tentative and approved; reconcile them with the official schedule rather than duplicate them. The common proposal safeguards govern them. No school-specific facts, school timezone, real child examples, sender domains or private sources were copied into the new behavior bundle. The bundled default SEES profile points to existing public facts, dates, menu, sender suggestions and topic-index sources; verify their freshness/content and original evidence when used. Parents do not assemble a separate pack.

## Change boundary for an actual future upgrade

This draft does not execute a state migration. Follow VERSIONING at a run boundary: validate a complete version, keep a recoverable private checkpoint where possible, preserve corrections/completions/declines/delivery and uncertain-action history, revalidate proposals, and never expand permissions. Incompatible or missing state blocks dependent actions, not all useful on-demand help. Release review must check both changed behavior and actual host capability evidence.

## Review wording revision: draft.1 to draft.3

Draft.3 clarifies that the generated bundle alone is the parent handoff; the manifest remains an optional maintainer integrity companion. It also distinguishes host capability availability from transient operational health and parent consent. No other behavior changes. Draft.2 is reserved for the evaluator's synthetic successor and is not an implementation release. Completion/correction and permission preservation rules remain unchanged.
